## Taxonomy

| Pattern | What it looks like in the first 3s |
|---|---|
| `problem-callout` | Names the viewer's problem out loud before anything else |
| `unexpected-visual` | Opens on a shot that does not read as an ad |
| `contrarian` | States the opposite of the category's common advice |
| `demo-cold-open` | Product doing the thing, no setup, no talking head |
| `social-proof` | Opens on someone else's reaction or result |
| `direct-address` | "If you _____, watch this." Names the segment |
